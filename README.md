## Abstract
XMalGuard is an advanced, AI-driven malware analysis platform designed to detect zero-day threats in Windows executables (PE files). Traditional antivirus engines rely heavily on signature matching, which fails against newly obfuscated malware. XMalGuard solves this by utilizing Static Analysis and Machine Learning to evaluate the structural and mathematical properties of files, alongside Explainable AI (SHAP) to provide transparent insights into the AI's decision-making process. The system integrates Threat Intelligence to seamlessly cross-reference hashes against known threat databases.

## Setup and Execution Instructions

### Prerequisites
- Node.js v18+
- Python 3.10+

### 1. Backend Setup (FastAPI & ML)
```bash
cd src/backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Frontend Setup (React & Vite)
```bash
cd src/frontend
npm install
npm run dev
```

### Quick Start
You can also simply double-click the `start_servers.bat` script located in the root directory to launch both the frontend and backend servers simultaneously on a Windows machine. The application will be accessible at `http://localhost:3000`.

## Repository Directory Structure
* `/src`: Contains the source code for the React frontend, FastAPI backend, and utility scripts.
* `/docs`: Contains project documentation, viva preparation materials, and architecture notes.
* `/data`: Data sources and synthetic generation scripts (Note: Large datasets like EMBER are ignored via `.gitignore` to comply with storage and licensing limits).
* `/results`: Output metrics and SHAP explanation plots generated by the model.
* `/reports`: Final review reports and phase submission documents.
