ABSTRACT
Malware represents an escalating global cyber threat, with millions of novel zero-day variants emerging annually to evade conventional signature-based antivirus solutions. Traditional static analysis relies on brittle byte patterns, while dynamic analysis requires resource-intensive sandboxing vulnerable to runtime evasion. This project proposes XMalGuard, a next-generation interpretable static analysis framework that parses Windows Portable Executable (PE) headers, entropy distributions, and import anomalies without code execution. Leveraging tree-based ensemble learning (Random Forest and XGBoost) coupled with game-theoretic SHAP (SHapley Additive exPlanations), XMalGuard quantifies exact feature attribution per prediction. By synthesizing ML probabilities, low-level structural heuristics, and real-time Threat Intelligence into a composite 0–100 risk score, the system delivers high-throughput, transparent zero-day threat mitigation.
*This is an enterprise-grade research prototype for SOC threat triage and security auditing.
OBJECTIVES
1 Static PE Parsing: Extract 35 structural features (headers, sections, imports, entropy, UPX packing) without dynamic code execution.
2 Standardize Dimensions: Preprocess, scale, and normalize tabular binary properties against official EMBER benchmark distributions.
3 Ensemble ML Classifiers: Train and benchmark Random Forest and XGBoost architectures for high-precision malware detection.
4 SHAP Explainability: Implement TreeExplainer to break down feature contributions and eliminate the AI black-box dilemma.
5 Composite Risk Scoring: Formulate a weighted 0–100 threat score combining ML confidence, PE anomalies, and import risks.
6 Threat Intelligence: Correlate cryptographic file hashes (SHA-256) with global intelligence feeds (VirusTotal) for threat attribution.
7 SOC Analyst Dashboard: Deploy an interactive web application with batch dataset streaming and exportable audit reports.
KEY INNOVATIONS
Non-Executing Static PE Reverse-Engineering
Safely extracts metadata, section entropy, and Windows API imports with zero risk of malware execution.
Game-Theoretic SHAP Interpretability
Breaks down predictions into exact positive/negative contributions, empowering analysts to verify AI verdicts.
Multi-Factor Composite Risk Scorer (0–100)
Combines ML probability (50%), structural heuristics (20%), threat intel (20%), and imports (10%) for resilient defense.
High-Throughput Batch Dataset Processing
Streams compressed JSONL benchmark archives (EMBER) in capped memory batches without server bottlenecks.
Unified SOC Threat Triage Platform
Delivers interactive prediction waterfalls, historical threat auditing, and instant HTML/PDF report exports.
